# Скины

### Способ #1

> Установить скин — `/skin set <nickname>`

### Способ #2 <a href="#sposob-2" id="sposob-2"></a>

> Установить скин по ссылке — `/skin url <url> [classic/slim]`
>
> * `<url>` - ваша ссылка
> * `classic` - обычные руки
> * `slim` - узкие руки

{% hint style="success" %}
Чтобы установить свой скин, воспользуйтесь [этой инструкцией](https://skinsrestorer.net/docs/features/skin-url). _Перевод скоро..._
{% endhint %}
