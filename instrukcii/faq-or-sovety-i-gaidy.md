# FAQ | Советы и гайды

<details>

<summary><img src="../.gitbook/assets/image (14).png" alt="" data-size="line"> Гайд Litematica от deportt</summary>

Тут вы узнаете, как пользоваться **Litematica** для сохранения и загрузки схем построек в Minecraft.

Этот гайд — краткая инструкция по основным функциям мода.

**Что нужно:**

Моды **Fabric API, Litematica, MaLiLib**;

Файл схемы формата **.litematic**.

**Управление:**

Клавиша **M** — открыть главное меню;

Палка (**ПКМ/ЛКМ**) — выделить область.

**Что делаем:**

Чтобы **создать схему**, нужно выделить постройку палкой от одного угла до другого.

После этого нажмите **M → Area Selection Browser → New Selection**.

Задайте название выделению и нажмите **CTRL + ALT + S**, чтобы сохранить схему.

Чтобы **загрузить схему**, нажмите **M → Load Schematic** и выберите нужный файл.

После загрузки схемы в мире появится голограмма постройки, по которой можно строить.

Если блок поставлен правильно, он станет **зеленым** или исчезнет из подсветки. Если неправильно — будет **красный**.

**Полезные фишки:**

Можно включить **режим слоев**, чтобы строить постройку поэтапно. Клавиши для него настраиваются в управлении.

Функция **Easy Place** автоматически переключает нужный блок в руку.

Чтобы убрать схему, откройте **M → Loaded Schematics → Unload**.

Папка со схемами обычно находится по пути **.minecraft/schematics**.

</details>
