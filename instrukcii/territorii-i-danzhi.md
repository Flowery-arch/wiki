# Территории и данжи

### Территории

{% hint style="warning" %}
Полноправной территорией игрока/гильдии считается та область мира (от бедрока до верхней границы), которая обозначена:

* Табличками по 4-м сторонам
{% endhint %}

Максимально дозволенный приват для:

* Игрока - 150 блоков
* Официально зарегистрированной гильдии считается 300 блоков вокруг от центра

{% hint style="success" %}
Если территория застроена или планируется масштабный проект, игрок или президент имеют право на расширение с официального разрешения Администрации Сервера
{% endhint %}

> Исключением правила владения территорией являются ситуации, когда игрок добывает сгенерированные руды под территорией другого игрока.

### Данжи

{% hint style="warning" %}
Полноправным данжем игрока считается область всей структуры, обозначенная:

* Табличками с подписью
{% endhint %}

Разрешается бронировать:

* Не более 2-х структур/данжей на одно игрока
* Не более 4-х структур/данжей на город
  * Исключениями являются структуры расположенные на территории города

{% hint style="danger" %}
Бронируя структуру, вы должны оставить доступ к сундукам и хранилищам естественной генерации
{% endhint %}
